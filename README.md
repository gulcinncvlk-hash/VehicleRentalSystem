# 🚗 Araç Kiralama Otomasyonu (Vehicle Rental System)

Bu proje, Nesne Yönelimli Programlama (OOP) dersi kapsamında geliştirilmiş, Java tabanlı bir araç kiralama otomasyon sistemidir. Hem konsol (terminal) üzerinden hem de Grafik Arayüz (Swing GUI) ile çalışabilmektedir.

## 🎯 Projenin Amacı
Kullanıcıların araçları listelemesi, müsaitlik durumunu kontrol etmesi, kiralama yapması ve iade işlemlerini gerçekleştirmesi sağlanmıştır. Projede *Kalıtım (Inheritance), **Polimorfizm, **Interface* ve *Encapsulation* gibi temel OOP prensipleri aktif olarak kullanılmıştır.

## 🛠️ Kullanılan Teknolojiler
* *Dil:* Java (JDK 21)
* *Arayüz:* Java Swing (GUI)
* *Test:* JUnit 5
* *Çizimler:* UML Class & Use-Case Diagrams (Mermaid/Draw.io)
* *Versiyon Kontrol:* Git & GitHub

## 🚀 Özellikler
* ✅ *Araç Listeleme:* Benzinli ve Elektrikli araçların ayrıştırılması.
* ✅ *Kiralama İşlemi:* Seçilen gün sayısına göre dinamik fiyat hesaplama.
* ✅ *İade Sistemi:* Araç iade edildiğinde tekrar "Müsait" durumuna geçmesi.
* ✅ *Grafik Arayüz:* Kullanıcı dostu pencereli menü sistemi.
* ✅ *Birim Testleri:* CarInventory ve Car sınıflarının hata yönetimi testleri.

## 📂 Proje Yapısı
* src/main/java/org/example -> Kaynak kodlar (Backend & GUI)
* src/test/java -> JUnit test dosyaları
* Dokumanlar/ -> UML Diyagramları ve Rapor görselleri
